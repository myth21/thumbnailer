## Инструкция по запуску тестов.

Тест нужно запускать последовательно. После тестов созданные изображения должны удаляться.
Это можно сделать вручную командой ```make remove-images```.
Сначала проверить наличие необходимых кодов для обработки изображения в базе.
```
vendor/bin/codecept run Functional DatabaseCest
```

После идет два сценария тестов. 
Первый отправить сообщения в очередь, чтобы изображения обработались обработчиков. 
Второй через HTTP запрос, чтобы изображения обработались напрямую сервисными классами.

#### Вариант 1

Отправить сообщение в очередь на обработку изображения по коду группы.
```
vendor/bin/codecept run Functional QueueCest
```

Проверить существование обработанных изображений.
```
vendor/bin/codecept run Functional FilesystemCest
```

#### Вариант 2

Отправить HTTP запрос с кодом группы.
```
vendor/bin/codecept run Acceptance BrowserCest
```
